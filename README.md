# Asistente Inteligente de Pendientes y Pagos

Aplicación multiplataforma para la gestión de pagos, cuentas y recordatorios,
con evolución progresiva hacia un sistema inteligente basado en datos.

## Tecnologías
- Frontend: Ionic + Angular
- Backend: Node.js + NestJS
- Base de datos: PostgreSQL
- Autenticación: Google OAuth + JWT
- Cloud: Google Cloud / Firebase

🚧 En desarrollo – fase de modelado de dominio y arquitectura base.
